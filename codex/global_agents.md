# Personal Codex Defaults

## Working Agreements

- When I ask a question, answer the question only.
- Do not edit, create, delete, or move files unless I explicitly ask you to make
  a change.
- Do not run mutating commands unless I explicitly ask for them.
- Treat prompts like "how do I", "what should go in", "is this possible",
  "explain", and "review" as discussion-only unless I clearly ask you to
  implement.
- Before editing files, briefly state what you intend to change.
